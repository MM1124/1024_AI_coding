## 第三轮迭代（7 项优化，已完成）
1. **功能点锁定不可解锁**：`req.confirmed` 即锁定为基准 SSOT，锁定后**无解锁入口**；`fp-del` 与 `fp-add` 在锁定后禁用；「编辑」按钮文案变「变更编辑」，保存不再直接落库，而是生成**需求变更单**（`DB.changeRequests`），经管理者审批通过后自动生成新版本（`versionOf` → v1.1）并留痕。未锁定阶段才可自由增删改。
2. **阶段门禁（前一阶段结果校验）**：新增 `E.stageGate(DB, reqId)`，按当前阶段返回校验项清单（每项 pass/detail）。分析阶段看「功能点已锁定 + 全部分析排期且已完成」；开发阶段看「开发任务全部完成（功能点维度 100%）+ 无未排期任务 + 无待审批变更单」；测试阶段看「测试记录全完成 + 功能点维度 100%」；验收阶段看「组织验收结论已出」。未通过则「提交下一阶段」按钮禁用并提示待完成项数。
3. **计划变更与需求变更 + 变更审批**：`changeRequests` 支持 kind=计划变更/需求变更，含 before/after/reason/payload；`E.planDiff(task, draft)` 自动算差异（工时/实施人/周期），无差异不允许提交空单；管理者在计划看板/执行跟踪审批（通过即写入 payload 并生成变更留痕，驳回需填意见）。
4. **手动添加计划入口**：分析/开发/测试三块计划各自有「手动添加X计划」按钮 + 独立弹窗。**弹窗新增联动**（本轮补）：切换计划类型自动按角色过滤执行人（分析→PM / 开发→DEV / 测试→QA），填工时后 `#mpPreview` 实时预览推荐周期与依据；弹窗未打开时联动安全返回。
5. **开发/测试阶段计划分离**：排期中心拆为三张独立卡片（1 分析阶段计划 / 2 开发阶段计划 / 3 测试阶段计划）；`testRecords` 升级为可独立排期（start/end/planDaily/draftAssignee/draftHours），`personLoad` 计入测试记录占用（`excludeTestId` 可排除自身）。
6. **计划看板可读性重做**：新增 `E.scheduleLanes(DB, {from, count})` 按人泳道渲染时间轴（横轴工作日、纵轴成员，条状块按 分析/开发/测试 三色区分，已完成灰化删除线，窗口外自动裁剪）；查看即可见「谁在哪几天做什么」，替代原甘特式堆叠。
7. **导航改侧边栏**：`.tabs` 顶栏页签 → `<aside class="sidebar">` 左侧固定导航（编号 + 标题 + 描述 + 待办角标），新增 `.page-head` 页头（视图名 + 说明 + 角色标签 + 当前需求）；修复「首个屏消失」问题，越权页签自动回落本角色首页（`render()` 内 `canView` 兜底）。
